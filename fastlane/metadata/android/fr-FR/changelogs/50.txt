ZigDash 2.7.1 : une configuration plus simple, testée dans une vraie maison Home Assistant. Vous pouvez coller le lien de Home Assistant (comme http://192.168.1.20:8123) dans le formulaire du broker. Quand la recherche trouve plusieurs brokers, chacun dit ce qu'il est : Home Assistant, hub SMLIGHT ou Zigbee2MQTT. Les appareils sans nom s'affichent « Motion sensor f66f », les capteurs de température et d'humidité sont cochés, et un identifiant refusé indique où trouver le bon.
