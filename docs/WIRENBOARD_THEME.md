# WireDash green theme

The default theme uses Wiren Board green, matching the launcher and startup icon.

| Role | Light | Dark |
| --- | --- | --- |
| Active device fill | `#5CB400` | `#84CE36` |
| Primary buttons and links | `#3D7800` | `#84CE36` |
| Page background | `#F5F8F1` | `#11170E` |
| Device surface | `#FFFFFF` | `#1B2416` |

The darker light-mode primary keeps white button labels and links readable.
Warnings retain a distinct warm hue. The existing Material You option still
harmonizes the theme with the user's selected wallpaper colours.

The theme and contrast tests cover the default light/dark palettes and green
and rose Material You palettes. Golden images cover phone, tablet, RTL and
large-text layouts.
